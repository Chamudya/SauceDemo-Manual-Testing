# SauceDemo – Manual Testing Project

## Project Overview
This project focuses on manual testing of the SauceDemo e-commerce web application. The purpose is to verify the functionality of the application, identify potential defects, and document testing results using standard software testing practices.

## Application Under Test
- **Website:** https://www.saucedemo.com/
- **Testing Type:** Manual Testing
- **Testing Approach:** Functional Testing
- **Tools:** Microsoft Excel, Microsoft Word, Web Browser

## Testing Scope
- Login functionality
- Product inventory
- Shopping cart
- Checkout process
- Input validation
- Positive and negative testing

## Testing Activities
- Prepared a test plan.
- Designed test scenarios and test cases.
- Executed manual test cases.
- Recorded actual and expected results.
- Identified and documented defects where applicable.
- Prepared a test summary report.

## Testing Deliverables
- Test Plan
- Test Scenarios
- Test Cases
- Bug Reports
- Test Execution Report
- Test Summary Report
- Testing Screenshots

## Skills Demonstrated
- Manual Software Testing
- Functional Testing
- Test Case Design
- Positive and Negative Testing
- Defect Reporting
- Test Documentation

## Project Objective
To gain practical experience in manual software testing and understand how QA engineers verify application functionality and document testing outcomes.
